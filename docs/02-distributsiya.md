# Дистрибуция

Артист **не загружает** трек напрямую в Яндекс Музыку. Только через дистрибьютора-партнёра.

Официально: https://music.yandex.ru (раздел для правообладателей / партнёры-дистрибьюторы).

## Кого выбрать (РФ, 2026)

| Ситуация | Сервис | Ссылка | Заметка |
|---|---|---|---|
| Старт, 0 ₽ | FreshTunes | https://freshtunes.com/ru | Яндекс, VK, Звук; вывод в РФ. Питчинг слабый. |
| Редкие релизы, фикс | MusicAlligator | https://musicalligator.ru | Плата за релиз, ~80%+ роялти, рубли. |
| ИП/ООО, каталог | ZVONKO digital | https://zvonkodigital.com | Крупный агрегатор, условия индивидуальные. |
| Электроника / Beatport | Imixes | https://imixes.ru | Часто эксклюзив на год — читайте договор. |

**Не как основная схема из РФ:** DistroKid, TuneCore, Amuse, ONErpm — выплаты и/или Яндекс+VK.

**Не отдавать дистрибуцию** маленькому «лейблу» за % с мастера, если они только заливают то, что делает FreshTunes бесплатно.

## Что указать в релизе

- **Artist name** — как будете жить 5 лет (без опечаток).
- **Label** — название группы или ваш ООО, **не** чужой бренд «за красивое».
- Жанр — один основной + 1–2 доп., честно.
- Язык вокала.
- Авторы / композиторы — как в договоре группы.
- ISRC выдаст дистрибьютор, не выдумывайте.
- Обложка: квадрат, **3000×3000 px**, без логотипов сторов, без URL, без «album», читаемый текст.
- Аудио: WAV/FLAC, 44.1 или 48 kHz, без клиппинга, без 3 секунд тишины «для солидности».
- Explicit — если мат, маркируйте.

Дата релиза: **пятница** удобна миру, для РФ не догма. Важнее не пересечься с вашим же концертом в тот же день без сил на промо.

## Сроки

| Что | Когда |
|---|---|
| Загрузка дистрибьютору | за 21–28 дней |
| Появление в каталоге Яндекса | часто 5–14 дней после модерации |
| Кнопка питчинга BandLink | 2–4 дня после подтверждения релиза на Яндексе |
| Питч редакторам | ≥ 14 дней до даты релиза |

Не ставьте релиз «завтра». Потеряете питч.

## После загрузки

1. Проверить карточку на Яндекс, VK, Apple (если есть): обложка, текст, порядок треков.
2. Собрать UPC / ссылки — пригодятся для верификации BandLink.
3. Не удалять и не перезаливать релиз в день выхода — ломает статистику.
