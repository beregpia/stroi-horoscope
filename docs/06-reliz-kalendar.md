# Календарь релиза

Отсчёт от **даты выхода** T.

## T−28…21

- [ ] Мастер, обложка, тексты, credits готовы.
- [ ] Загрузка в FreshTunes / MusicAlligator, дата T, лейбл = группа.
- [ ] Договор между участниками подписан.
- [ ] Посты задуманы: 4 сниппета, 1 «история песни», 1 репетиция.

## T−21…14

- [ ] Релиз виден как upcoming / подтверждён на Яндексе.
- [ ] BandLink: верификация, смартлинк, **пресейв**.
- [ ] Питчинг Яндекс (BandLink).
- [ ] Питчинг VK (Анкеты / кабинет).
- [ ] Spotify pitch, если трек там будет.
- [ ] 15 писем кураторам небольших плейлистов.

## T−7

- [ ] Видеошот загружен.
- [ ] Анонс пресейва во всех сетях.
- [ ] Список, кому написать в день T (друзья, паблики, площадки, где играли).
- [ ] Проверка карточки: имя, обложка, порядок треков.

## День T

- [ ] Пост + сторис + Telegram: смартлинк, **просьба слушать на Яндекс Музыке**.
- [ ] Трек в сообществе ВК.
- [ ] Рассылка «дослушайте и лайкните профиль».
- [ ] Не релизить одновременно 12 треков, если нет аудитории — лучше 1 сингл.

## T+1…14

- [ ] Каждый день или через день: сниппет / закулисье / текст куплет.
- [ ] Смотреть BandLink: источники, дослушивания, гео.
- [ ] Отвечать всем, кто написал (плейлисты, бары, радио).
- [ ] Если тишина — не перезаливать трек. Готовить следующий сингл через 4–8 недель.

## Ритм года

Независимой группе достаточно: **сингл → сингл → EP**, а не «двойной альбом раз в три года без промо».

Концерт через 2–4 недели после сингла, не в тот же вечер, когда все силы ушли в постинг.
