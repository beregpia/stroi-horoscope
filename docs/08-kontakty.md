## Разово завести

- [ ] Почта группы вида `music@` или gmail без nick-1999.
- [ ] Telegram для букинга.
- [ ] Диск: мастера, обложки, фото press, one-sheet PDF (1 страница: фото, био 800 знаков, контакты, ссылки).
- [ ] Техрайдер (1–2 стр.) для клубов.

## Перед каждым синглом

- [ ] WAV + обложка 3000 + credits.
- [ ] Дистрибьютор, дата ≥ +21 день.
- [ ] BandLink пресейв.
- [ ] Питч Яндекс и VK.
- [ ] 10 писем плейлистам / пабликам.
- [ ] 4 единицы контента в календаре.

## Метрики (смотреть в BandLink / дистрибьюторе)

Не тщеславие «миллион», а:

- дослушивания %;
- уникальные слушатели 7 и 28 дней;
- сохранения / лайки;
- откуда трафик (карточка, волна, плейлист, внешние);
- гео (Москва / регионы).

Если через 28 дней ноль волны — трек не «мёртвый», просто следующий сингл пишите сильнее и не сжигайте бюджет на накрутку.
