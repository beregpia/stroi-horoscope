# Контент, паблики, концерты

## Соцсети (минимум, который работает)

Держать 3 канала, не 12:

1. **ВК-сообщество** — основная РФ-аудитория, музыка, события.  
2. **Telegram** — свои люди, анонсы, билеты.  
3. **Короткие видео** (VK Клипы / Shorts / Reels) — сниппеты.

Instagram/TikTok — по силам. Сайт не обязателен; смартлинк важнее.

Регулярность: 3–5 единиц контента в неделю в релизный месяц, 1–2 вне релиза.

Темы, которые не стыдно повторять: хук 10 сек, «как писали припев», репетиция, афиша, отзыв с концерта, текст на экране.

## Посевы в пабликах

Рок/инди: тематические паблики ВК (не «100к ботов»).

Письмо админу:

```
Привет. Группа «___», [город]. Новый трек: [ссылка].
Жанр: ___. Можно пост / клип у вас? Бартер или ваш прайс.
```

Платить имеет смысл **после** просмотра охвата похожих постов (лайки живые, комментарии не «круто!!1» с одного шаблона).

Shark Music и подобные — только тест одного пакета, **без** дистрибуции и без % с роялти.

## Концерты

Искать самим:

- афиши площадок вашего калибра (бары, клубы 100–400 человек);
- формы букинга на сайтах клубов;
- знакомые группы → «возьмите нас разогревом».

Письмо в клуб:

```
Здравствуйте. Группа «___», жанр ___, город ___.
Играли: [места, даты]. Видео с концерта: [ссылка 1–2 мин].
Ссылки: [BandLink]. Состав: N человек, бэклайн: [ударные/бас/2 гитары…].
Рассматриваем [месяц]. Готовы на вход/% по вашей схеме.
Контакт: имя, тел, Telegram.
```

Концертное бюро (типа локальной «Т.Е.М.А.»): только **конкретные даты**, комиссия с **их** концертов, без эксклюзива на бренд и записи.

Корпоративы — нормальные деньги на старте; не стесняться, но не отдавать 50% агенту за звонок, который вы сделали сами.

## Радио и СМИ

На старте: локальные онлайн-радио, телеграм-каналы «новая музыка», городские афиши.

Письмо:

```
Релиз «___» вышел ДД.ММ, ссылка BandLink.
Коротко о группе: 2 предложения.
Есть чистая версия / инструментал по запросу.
```

Федеральные СМИ без инфоповода (клип, тур, необычная история) почти не отвечают. Не покупать «статью в СМИ» на биржах с копипастой.
