# Готовые тексты: питч и письма кураторам

Подставьте своё в `[скобки]`. Не копируйте референсы, если не слушаете так. Цифры — только правдивые.

---

## 1. Питчинг Яндекс Музыки (BandLink)

Поле «описание / настроение / достижения». 500–900 знаков.

### Универсальный (рок / инди / альтернатива)

```
Город: [Москва]
Состав: [N человек], жанр: [инди-рок / постпанк / альтернатива]
Трек: «[Название]» — лид-сингл, релиз [ДД.ММ.ГГГГ]

О чём: [одна фраза: например «песня про то, как не отпускает город ночью»].
Настроение: [меланхолия, драйв, холод] . Темп ~[BPM] BPM.
Ориентиры по ощущению (не копия): [референс 1], [референс 2].

Зачем сейчас: [первый сингл / клип / концерт ДД.ММ в клубе ___].
Живые выступления: [площадки, если были].

Просим рассмотреть для редакционных подборок в духе новой русской гитарной музыки / инди / рок.
```

### Поп / синти / электроника

```
Город: [Москва]. Проект: [название], жанр: [синти-поп / электроника].
Трек: «[Название]», релиз [дата].

Хук в первом куплете, настроение: [танцевальный / ночной / лёгкий].
BPM ~[число]. Короткий сингл [X:XX], без воды.

Референсы по настроению: [2 имени].
Инфоповод: [релиз / клип / танцевальный сет].

Просим плейлисты: новая поп-музыка, электроника, танцевальное.
```

### Панк / ска / жёсткий рок

```
Группа «[имя]», [город], [панк-рок / ска-панк].
Трек «[название]», релиз [дата], хронометраж [X:XX], BPM ~[число].

Тексты [социальные / хулиганские / личные], живая запись / драйв.
Играли: [клуб, фестиваль — если правда].

Просим рок- и панк-подборки, «новое громкое».
Без накруток, один ключевой трек — этот.
```

### Хип-хоп / рэп

```
Артист/группа: [имя], [город], [хип-хоп / альт-рэп].
Трек «[название]», релиз [дата].

Тема: [одна строка]. Фичи: [если есть, имя]. Продюсер бита: [если важно].
Настроение: [уличный / меланхоличный / агрессивный].

Просим урбан / новый рэп / хип-хоп подборки.
```

### Короткий вариант, если мало знаков

```
«[Группа]» — [жанр], [город]. Сингл «[трек]» [дата].
Настроение: [3 слова]. Про [о чём]. BPM [N].
Концерт / клип: [факт]. Ключевой трек — этот.
```

## 2. Питчинг VK Музыка / «Анкеты»

Тот же смысл, короче:

```
«[Группа]», [жанр], [Москва].
Сингл «[Название]» — [дата], ссылка: [VK или BandLink].
Настроение: [3 слова]. О чём: [1 предложение].
Просим добавить в редакторские плейлисты VK Музыки по жанру [жанр].
Контакт: [имя, Telegram @___].
```

## 3. Письмо куратору пользовательского плейлиста

Тема (если email): `Трек в плейлист «[название плейлиста]» — группа [имя]`

```
Здравствуйте!

Мы группа «[Название]», [жанр], [город].
Вышел / выходит [дата] трек «[Название трека]»:
[ссылка Яндекс или BandLink]
[ссылка VK Музыка]

По настроению близок к вашему плейлисту «[точное название]»
(нас зацепили треки вроде [1–2 исполнителя из ЭТОГО плейлиста]).

Если зайдёт — будем рады добавлению. Накруток нет.
Могу прислать WAV / короткую версию для сторис.

Спасибо,
[Имя]
[Telegram] | [телефон]
```

Если в личку ВК — убрать «Здравствуйте»-простыню, оставить 6–8 строк.

### Ещё короче (сообщение ВК)

```
Привет! Группа «[имя]», [жанр].
Новый трек: [ссылка]
Похоже на то, что у вас в «[плейлист]».
Можно добавить, если зайдёт? Спасибо.
```

## 5. Что писать своим в день релиза (чат / сторис)

```
Сегодня вышел «[трек]».
Очень нужно: открыть на Яндекс Музыке, дослушать до конца и лайкнуть
и трек, и профиль артиста. Это не «для статистики», так трек подхватывает
Моя волна.

Ссылка: [BandLink или прямая Яндекс]
```

Не: «зайдите на 10 секунд».

---

## 6. Как заполнять референсы

Берите 2 артиста **из того же ящика**, куда хотите попасть, не мировых гигантов в чужом жанре.

| Если вы | Референс-уровень |
|---|---|
| Постпанк / инди | русская гитарная сцена, не Radiohead + Скриптонит |
| Поп | актуальный русскоязычный поп вашего темпа |
| Панк | конкретные российские панк/альт группы |

Формула: «настроение как у A, гитары ближе к B» — честнее, чем «микстура всего».
