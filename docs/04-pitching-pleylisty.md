# Питчинг и плейлисты

## Что такое питчинг

Короткое письмо редактору стриминга: кто вы, какой трек, настроение, куда класть.

Это **не** покупка места. Отказ — норма. Повторно тот же трек не спамить каждую неделю.

## Яндекс Музыка (главное для РФ)

**Где:** BandLink → раздел аналитики / релиза → **«Отправить на питчинг»**.  
Не в FreshTunes и не в «напишите на почту Яндекса».

**Когда кнопка живая:**

1. Аккаунт верифицирован.
2. Дистрибьютор подтвердил релиз в Яндекс Музыке.
3. Дата релиза ещё **не наступила**.
4. Прошло 2–4 дня после подтверждения.

**Когда жать:** за 14–21 день до релиза.

### Что писать в форме

Поля обычно: ключевой трек, описание идеи, настроение, достижения.

Шаблон (подставьте своё, 500–900 знаков):

```
Город: Москва
Состав: [N человек], жанр: [например постпанк / инди-рок]
Трек: «Название» — лид сингл с [EP/альбома], релиз ДД.ММ.ГГГГ

О чём: [одна фраза сюжета]. Настроение: [ночь, драйв, меланхолия — 3 слова].
Темп: ~XXX BPM. Референсы по ощущению (не «звучим как»): [2 честных ориентира].

Почему сейчас: [концерт / клип / фит — один факт].
Где уже слушали: [клуб, город, число, если правда].

Просим рассмотреть для плейлистов: [названия 2–3 реальных редакционных,
например «Новая русская музыка», «Инди», «Рок» — смотрите актуальные
названия в приложении].
```

Не писать: «шедевр», «взорвём чарт», «слушают миллионы» при 200 стримах.

Новичкам (< ~5 тыс. месячных слушателей) трек могут вести через **Нитро** (холодный старт). Это не отказ.

Редакционный плейлист **«Искра»** — уже после того, как «Моя волна» подхватила трек. Туда не питчат «с улицы».

## VK Музыка

1. Трек в каталоге VK.
2. Сообщество группы живое (аватар, 5–10 постов, музыка прикреплена).
3. Заявка: приложение VK **«Анкеты»** → формы для музыкантов / плейлисты (название формы меняется).
4. Дублируйте суть питча Яндекса, короче.

Дополнительно: тематические **пользовательские** плейлисты.

Искать: в VK Музыке плейлисты по жанру с 5–50 тыс. подписчиков (не миллионники). Писать куратору в личку:

```
Здравствуйте. Мы группа «___», жанр ___. Новый трек: [ссылка VK].
Если зайдёт по настроению плейлиста «___» — будем рады добавлению.
Без накруток, релиз ДД.ММ.
```

10–20 писем вручную лучше, чем 200 копипаст.

## Spotify

https://artists.spotify.com → релиз → **Pitch a track** (нужен upcoming релиз, тоже заранее).

Для РФ-группы: делать, если есть зарубежный угол или англоязычный трек. Не вместо Яндекса.

## Платные «плейлист-промо»

Сайты «попадём в 100 плейлистов» почти всегда боты и мусорные плейлисты. Риск: антифрод Яндекса/VK, обнуление трека.

Исключение: официальная реклама площадки (например промо-инструменты Яндекса вроде **Импульс**, если доступен в BandLink) — это оплата **площадке**, не серому посреднику.

## Как понять, что питч сработал

- Трек появился в редакционном плейлисте (уведомление / карточка / аналитика BandLink: источник трафика «плейлисты»).
- Скачок уникальных слушателей в день релиза + удержание на 7-й день.
- Рост **дослушиваний**, не только стартов.

Нет ответа редактора = обычно нет. Не писать в поддержку Яндекса «почему не взяли».
