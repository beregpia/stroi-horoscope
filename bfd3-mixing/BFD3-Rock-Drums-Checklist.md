# 🥁 BFD3 → Cubase: чеклист сведения барабанов для рока

> Порядок важен: идите по этапам сверху вниз. Уровни и настройки — стартовые точки, дальше — уши.

---

## Этап 0 — Подготовка в BFD3

- [ ] Выбран рок-кит (бочка 22", металлический или глубокий деревянный рабочий)
- [ ] **Damping**: бочка — побольше (убрать гул), рабочий — умеренно
- [ ] **Tuning**: рабочий чуть вверх (панч), томы не конфликтуют друг с другом
- [ ] **Bleed** в микрофонах бочки и рабочего снижен до ~30–50% (но НЕ в ноль!)
- [ ] Встроенные эффекты BFD3 (EQ, компрессоры) выключены
- [ ] Ambient-каналы (OH, Room, Amb) оставлены включёнными

## Этап 1 — Мультивыход BFD3 → Cubase

- [ ] В микшере BFD3 каждый канал назначен на свой выход:
  - `Kick In → Out 1`, `Kick Out → Out 2`
  - `Snare Top → Out 3`, `Snare Bottom → Out 4`
  - `Hi-Hat → Out 5`, `Toms → Out 6–8`
  - `OH → St 9/10`, `Room → St 11/12`, `Amb → St 13/14`
- [ ] Cubase: **F11 → правый клик по BFD3 → Activate Outputs** — включены все выходы
- [ ] Моно-источники выведены в моно, амбиент — в стерео
- [ ] Панорама: бочка/рабочий в центр, хэт ~30–40% вбок, томы веером, **направление томов совпадает с OH**

## Этап 2 — Группы в Cubase

- [ ] Созданы группы: **KICK**, **SNARE**, **TOMS**, **ROOMS**, **DRUM BUS**
- [ ] Все группы и прямые каналы (HiHat, OH) заведены в **DRUM BUS**
- [ ] Созданы FX-каналы: **Drum Verb** (реверб) и **Smash** (параллельная компрессия)

```
Kick In ─┐
Kick Out ─┴─► GROUP: KICK ──────┐
Snare Top ─┐                    │
Snare Btm ─┴─► GROUP: SNARE ────┤
Toms 1-3 ────► GROUP: TOMS ─────┼─► GROUP: DRUM BUS ─► Stereo Out
HiHat ──────────────────────────┤
OH ─────────────────────────────┤
Room / Amb ─► GROUP: ROOMS ─────┘
```

## Этап 3 — Gain staging и фаза

- [ ] Пики каналов около **−18…−12 dBFS**, фейдеры на 0
- [ ] **Snare Bottom: полярность перевёрнута** (MixConsole → Pre → ø) — проверено на слух с Snare Top
- [ ] Kick In vs Kick Out: проверена полярность (выбран вариант, где больше низа)
- [ ] Соло OH + бочка + рабочий: низ не «худеет» при добавлении OH

## Этап 4 — Поканальная обработка

### Бочка (KICK)
- [ ] Kick In EQ: HPF 35–40 Гц · вырез −4…−6 дБ @ 300–450 Гц · +3…+5 дБ @ 3–5 кГц (щелчок)
- [ ] Kick In Gate (если мешает bleed)
- [ ] Kick Out EQ: +2…+4 дБ @ 50–60 Гц · LPF 8–10 кГц
- [ ] Группа KICK: Comp 4:1, **Attack 20–30 мс**, Release 50–100 мс/Auto, GR 3–5 дБ
- [ ] По вкусу: Magneto III, Saturation 20–30%

### Рабочий (SNARE)
- [ ] Snare Top EQ: HPF 70–90 Гц · тело +2…+4 дБ @ 150–250 Гц · −3…−5 дБ @ 400–600 Гц · +3 дБ @ 4–6 кГц
- [ ] Snare Bottom: HPF 300–400 Гц (только пружина), фейдер −6…−10 дБ ниже Top
- [ ] Группа SNARE: Comp 4:1, Attack 10–20 мс, Release 80–150 мс, GR 4–6 дБ
- [ ] Для агрессии: второй быстрый комп (1176-стиль), GR 2–3 дБ
- [ ] EnvelopeShaper: Attack +2…+4 дБ (если не хватает щелчка)
- [ ] Send → Drum Verb

### Томы (TOMS)
- [ ] Gate на каждом томе: Attack мин., Hold 100–200 мс, Release 200–400 мс
- [ ] EQ: HPF 50–60 Гц (флор) / 70–80 Гц (альты) · −4 дБ @ 300–500 Гц · +3 дБ @ 4–6 кГц
- [ ] Группа TOMS: Comp 4:1, Attack 20 мс, GR 3–4 дБ
- [ ] Send → Drum Verb

### Хэт
- [ ] HPF 200–300 Гц
- [ ] При резкости: узкий вырез или динамический EQ @ 3–4 кГц

### Оверхеды (OH)
- [ ] Выбран подход: «только тарелки» (HPF 400–500 Гц) или «полная картина» (HPF 100–150 Гц)
- [ ] Шелф +1–2 дБ выше 10 кГц (воздух)
- [ ] Компрессия лёгкая (2:1, 1–2 дБ) или нет

### Room / Amb (ROOMS) — «размер» барабанов
- [ ] Компрессор: Ratio 8:1–20:1, Attack/Release быстрые, **GR 10+ дБ** — пусть качает
- [ ] По вкусу: Magneto III / Distortion для грязи
- [ ] Фейдер вкачен под микс (от «чуть воздуха» до «стадиона»)

## Этап 5 — Параллельная компрессия (Smash)

- [ ] Send'ы с KICK, SNARE, TOMS → FX Smash (пост-фейдер, 0 дБ)
- [ ] Комп: Ratio 10:1+, Attack мин., Release быстрый, GR 10–15 дБ
- [ ] EQ на Smash: +3 дБ @ 100 Гц и @ 8 кГц
- [ ] Фейдер Smash поднят с −∞ до плотности (обычно −10…−6 дБ от основного)

## Этап 6 — Реверберация (Drum Verb)

- [ ] REVerence (Plate/Studio Room) или RoomWorks · plate **1.2–1.8 с**
- [ ] HPF 300 Гц + LPF 8 кГц на ревербе
- [ ] **Pre-delay 20–40 мс**
- [ ] Бочка в реверб не идёт (или чуть-чуть)

## Этап 7 — Драм-бас (DRUM BUS)

- [ ] Glue-комп: 2:1–4:1, Attack 10–30 мс, Release Auto/0.1 c, **GR всего 1–3 дБ**
- [ ] Magneto III: Saturation 15–25%
- [ ] Финальный EQ: лёгкая «улыбка» (+1–1.5 дБ @ 60–80 Гц и @ 10 кГц) — по необходимости
- [ ] Лимитер на пару дБ — если выпрыгивают пики томов

## Этап 8 — Финальные штрихи

- [ ] Автоматизация: ROOMS и Drum Verb +1.5–2 дБ в припевах
- [ ] Velocity/humanize в Groove-редакторе BFD3 (особенно хэт)
- [ ] Баланс от бочки: бочка → рабочий (примерно поровну) → OH → остальное
- [ ] Сравнение с референсом на одинаковой громкости
- [ ] Проверка в **моно** (Control Room) — фазовые проблемы OH

---

## ❌ Типичные ошибки

1. Сведение стереовыхода BFD3 вместо мультивыхода
2. Забытая полярность Snare Bottom
3. Слишком быстрая атака компрессора на бочке/рабочем — убивает панч
4. Полностью вырезанный bleed — «мёртвый» звук
5. Реверб без HPF — каша внизу
