# 🎛️ Карточки пресетов Cubase — BFD3 Rock Drums

> **Как пользоваться:** наберите цепочку на канале по карточке → правый клик по слотам инсертов
> → **Save FX Chain Preset** → назовите как указано. Дальше пресет доступен в один клик
> в MediaBay и на любом канале (иконка пресета вверху канала → Load FX Chain Preset).
>
> Пресеты лежат в: `%AppData%\Steinberg\Cubase 15\Presets\FX Chain Presets` (Win)
> или `~/Library/Application Support/Steinberg/Cubase 15/Presets/FX Chain Presets` (Mac) —
> папку можно бэкапить и переносить.

## 💾 Бонус: сохранить ВСЁ одним пресетом

Когда набрали весь шаблон (группы, FX-каналы, роутинг):

1. Выделите **все** барабанные треки (каналы BFD3 + группы + FX)
2. Правый клик → **Export Selected Tracks…** → сохраните как Track Archive (`.xml`)
3. В новом проекте: **File → Import → Track Archive** — вся структура с плагинами
   и настройками восстановится за секунды!

Либо сохраните весь проект как **шаблон**: File → Save as Template — и каждый новый
рок-трек начинайте уже с готовой барабанной сессией.
